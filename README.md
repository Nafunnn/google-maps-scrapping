**Google Maps Scrapping Data**

How To Use

- Clone This Repository
- Open Terminal and type "npm install" or "yarn install" and wait until done
- For run this code u must type "npm run start"
- Type what you want to search for, then click enter
- Wait until the process is complete
- Open the result folder to see the data scraping results
